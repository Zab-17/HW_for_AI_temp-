# Data

The Magic Wand dataset is not committed. Download `data.tar.gz` from the course
materials and extract it here so that `data/{wing,ring,slope,negative}/` exist.

Splits (see project spec and FAQ):

- Train: hyw, shiyun, tangsy, dengyl, jiangyh, xunkai; `negative_3`
- Validation: pengxl; `negative_2`, `negative_4`
- Test: liucx, zhangxy; `negative_1`, `negative_5`
